# Receipt Management Platform

Receipt Management Platform for offline-first receipt capture, OCR, and export workflows.

## Current status

Phase 1 has been initialized with the base project structure for a GitHub Pages-friendly static application.

## Project structure

- `index.html` — initial application entry page
- `src/styles/` — shared styles
- `src/scripts/` — future client-side JavaScript
- `src/assets/` — future static assets
- `TASKS.md` — phased execution checklist
- `SYSTEM_PROMPT.md` — repository build rules

## Local preview

Serve the repository root with any static file server, for example:

```bash
python3 -m http.server 4173
```
