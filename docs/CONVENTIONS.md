# CONVENTIONS

- JavaScript identifiers: `camelCase`
- CSS classes/selectors: `kebab-case`
- Constants: `UPPER_SNAKE_CASE`
- Event names: `noun:verb` (example: `receipt:created`)
- File names: `kebab-case`
- Dates: ISO 8601 strings
- Currency storage: integer cents in persisted models where applicable
- Module format: native ES6 modules
